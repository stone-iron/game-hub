# 겜허브 – 설치 없이 바로 하는 실시간 보드게임

친구와 6자리 코드만 공유하면 바로 함께 할 수 있는 브라우저 보드게임 플랫폼입니다.
**오목, 그림맞추기, 십자격돌** 세 가지 게임을 하나의 공통 구조(방 · 입장 코드 · 재접속 · 타이머) 위에서 제공합니다.

## 실행

```bash
./mvnw spring-boot:run
```

브라우저에서 http://localhost:8090 에 접속합니다. (여기모여 백엔드 8080과 겹치지 않도록 8090 포트를 사용합니다.)
창을 두 개 열거나 다른 브라우저로 접속하면 혼자서도 대결을 테스트할 수 있습니다.

```bash
./mvnw test   # 단위 테스트 + 동시성 테스트
```

회원 정보는 별도 설치 없이 프로젝트 폴더의 `data/` 에 H2 파일 DB로 저장됩니다. (`.gitignore`에 포함)
MySQL로 바꾸려면 `application.properties`의 주석을 참고해 접속 정보만 바꾸고 H2 대신 `mysql-connector-j`를 추가하면 됩니다.

## 기술 스택

- Java 25, Spring Boot 4.1
- Spring WebSocket (STOMP), Spring Web, Bean Validation
- Spring Data JPA, H2 (회원 · 로그인 상태 저장, MySQL로 교체 가능)
- 화면: HTML, CSS, JavaScript (STOMP.js)
- 테스트: JUnit 5

## 게임

| 게임 | 인원 | 진행 방식 | 핵심 구현 |
|---|---|---|---|
| 오목 | 2명 (혼자하기: 컴퓨터) | 턴제, 한 수 60초 | 서버가 차례·빈칸·5목·시간 초과를 판정, 초급·중급·고급 컴퓨터 상대 |
| 그림맞추기 | 2~10명 | 2명이 모이면 자동 시작, 중간 입장 가능 | 제시어는 출제자에게만 전송, 펜·지우개·채우기·직선·사각형·원, 되돌리기/다시하기 |
| 십자격돌 | 1~4명 (혼자하기 가능) | 7×7 십자말을 동시에 풀고 먼저 맞힌 사람이 단어 차지 | 같은 단어에 동시에 정답이 와도 한 명만 차지, 오답 후 2초 대기 |

## 설계 포인트

### 1. 게임 규칙만 바꿔 끼우는 구조

```
GameRule (게임 종류별 새 판 생성)  ──>  GameSession (한 판의 규칙과 상태)
   OmokRule / DrawingRule / CrosswordRule     OmokSession / DrawingSession / CrosswordSession
```

방 관리, 입장 코드, 재접속, 타이머, 메시지 전송은 모두 `RoomService`가 담당하고,
게임마다 다른 것은 `GameRule`과 `GameSession` 구현체뿐입니다.
새 게임은 이 두 클래스를 만들고 `GameConfig`에 빈 하나만 추가하면 기존 기능을 그대로 사용합니다.
게임 규칙 클래스는 Spring에 의존하지 않아 순수 Java 단위 테스트로 검증합니다.

### 2. 서버가 판정한다 (클라이언트 조작 방지)

클라이언트는 "여기에 두겠다", "이 단어가 정답이다" 같은 **의도만** 보냅니다.
차례 확인, 규칙 검사, 정답 판정, 점수 계산은 모두 서버에서 합니다.
정답(십자말 글자, 그림 제시어)은 맞히기 전까지 공개 메시지에 절대 담지 않습니다.

### 3. 방 단위 락으로 동시 요청 처리

방 하나의 상태를 바꾸는 모든 작업은 `RoomService.withRoom()`에서 **방 단위 락**을 잡고 실행됩니다.

- 같은 방의 요청은 도착 순서대로 하나씩 처리 → 십자격돌에서 같은 단어에 정답이 동시에 몰려도 먼저 처리된 한 명만 차지
- 서로 다른 방은 락을 공유하지 않아 서로 기다리지 않음
- 게임 규칙 코드는 락 안에서만 호출되므로 동시성을 신경 쓰지 않고 규칙에만 집중

`RoomServiceTest`에서 **40개 스레드가 같은 단어에 동시에 정답을 보내도 정확히 1명만 성공**하는 것을 검증합니다.

### 4. 로그인 없는 본인 확인과 재접속

- 입장하면 무작위 토큰을 발급하고 본인에게만 돌려줍니다. 공개 메시지에는 토큰을 담지 않습니다.
- 비공개 메시지(제시어, 오류)는 토큰이 포함된 주소로 보내 본인만 받습니다.
- 새로고침하거나 연결이 끊겨도 같은 토큰으로 돌아오면 원래 자리로 복귀합니다.
  대기실은 20초, 게임 중에는 60초 안에 돌아오지 않으면 퇴장(게임 중이면 기권) 처리합니다.

### 5. 오목 컴퓨터 상대 (혼자하기)

빈칸마다 "내가 두면 얼마나 좋은가(공격)"와 "상대가 두면 얼마나 위험한가(수비)"를 점수로 매겨 가장 좋은 칸에 둡니다.
실력은 판을 읽는 방식으로 나눴습니다.

| 난이도 | 읽는 방식 |
|---|---|
| 초급 | 가로·세로만, 이어진 돌만 셈 (대각선 위협을 놓침) |
| 중급 | 네 방향 모두, 이어진 돌과 열린 끝을 셈 |
| 고급 | 다섯 칸 묶음(윈도우)마다 돌을 세서 ●●_●● 같은 띄운 모양까지 읽음 |

컴퓨터도 `GameBot` 인터페이스를 통해 사람과 똑같이 `GameSession.handle()`로만 수를 두므로, 같은 규칙 검사를 거칩니다.
`OmokAiTest`에서 고급이 초급을 상대로 대부분 이기는지, 모든 난이도가 이기는 수와 막아야 할 수를 찾는지 검증합니다.

### 6. 그림 동기화

그리기 도구는 "그리기 명령"(도구, 좌표 0~1 비율, 색, 굵기, group)으로 저장하고 모두가 같은 순서로 다시 그립니다.
펜처럼 여러 조각으로 나눠 보내는 획은 같은 group 번호로 묶어, 되돌리기 한 번에 한 획이 통째로 지워집니다.
나중에 들어온 사람도 서버에 저장된 명령으로 같은 그림을 봅니다.

### 7. 부정 요청 방지

- 십자격돌: 오답 후 2초 동안 답을 낼 수 없어 무차별 대입을 막습니다.
- 그림맞추기: 출제자나 이미 맞힌 사람은 정답이 포함된 채팅을 보낼 수 없습니다.
- 닉네임 길이, 그림 좌표 개수·범위, 색상 형식을 서버에서 검증합니다.

### 8. 회원가입 · 로그인 (선택)

로그인 없이도 게임을 할 수 있고, 회원이 되면 **닉네임을 나만 쓸 수 있습니다.**

- **비밀번호 저장**: JDK 표준 PBKDF2(HMAC-SHA256, 21만 회 반복) + 회원별 무작위 솔트. 반복 횟수를 해시와 함께 저장해 나중에 올려도 기존 회원은 그대로 로그인됩니다.
- **로그인 토큰**: 32바이트 무작위 토큰을 발급하고, DB에는 SHA-256 해시만 저장합니다. DB가 유출돼도 토큰을 그대로 쓸 수 없습니다. 7일 뒤 만료되고 한 시간마다 만료된 기록을 지웁니다.
- **무차별 대입 방지**: 같은 아이디로 5번 연속 틀리면 5분 동안 로그인을 막습니다.
- **가입 여부 노출 방지**: 아이디가 없을 때도 같은 시간 동안 비밀번호를 비교하고, 같은 오류 문구를 돌려줍니다.
- **중복 가입**: 미리 확인한 뒤에도 DB 유니크 제약이 마지막으로 막아, 동시에 같은 아이디로 가입해도 한 명만 성공합니다. (`AuthServiceTest`에서 20개 스레드로 검증)
- **닉네임 보호**: 로그인한 회원은 회원 닉네임으로만 참가하고, 게스트는 회원이 쓰는 닉네임을 쓸 수 없습니다.
- `AuthService`는 저장소 인터페이스(`MemberStore`, `AuthSessionStore`)에만 의존해, 테스트에서는 메모리 구현으로 DB 없이 규칙을 검증합니다.

## 통신 구조

| 방향 | 주소 | 내용 |
|---|---|---|
| REST | `POST /api/auth/signup · login · logout`, `GET /api/auth/me` | 회원가입(가입 즉시 로그인), 로그인, 로그아웃, 내 정보 (`Authorization: Bearer 토큰`) |
| REST | `POST /api/rooms` | 방 만들기 → 코드, 토큰 발급 |
| REST | `POST /api/rooms/solo` | 혼자하기 (오목: 컴퓨터 난이도 선택, 십자격돌: 혼자 풀기) |
| REST | `POST /api/rooms/{code}/join` | 코드로 입장 |
| REST | `GET /api/rooms` | 열린 방 목록 |
| REST | `POST /api/rooms/{code}/leave` | 나가기 |
| 클라이언트 → 서버 | `/app/rooms/{code}/hello · start · action · chat · reset` | 접속 알림, 시작, 게임 행동, 채팅, 다시 하기 |
| 서버 → 방 전체 | `/topic/rooms/{code}` | 공개 상태 |
| 서버 → 방 전체 | `/topic/rooms/{code}/events` | 그림 획, 채팅, 정답 알림 |
| 서버 → 본인 | `/topic/rooms/{code}/private/{token}` | 제시어, 오류 메시지 |

## 폴더 구조

```
src/main/java/com/stoneiron/gamehub
├── game                 공통 인터페이스 (GameRule, GameSession, ActionResult)
│   ├── omok             오목
│   ├── drawing          그림맞추기 (+ 제시어 목록)
│   └── crossword        십자격돌 (+ 퍼즐 검증, 퍼즐 모음)
├── room                 방 관리, 재접속, 타이머, REST/STOMP 컨트롤러
├── member               회원가입·로그인 (AuthService, 비밀번호 해시, 로그인 시도 제한)
│   └── jpa              회원·로그인 상태 저장소의 JPA 구현
├── config               게임 규칙 조립, WebSocket·회원 설정
└── common               API 오류 응답
src/main/resources/static   화면 (index.html, app.js, style.css)
```
